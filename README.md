# Graduation Project Brainstorming App

A modern, full-stack web application designed for computer science students and teams to brainstorm, organize, and track graduation project ideas collaboratively. Featuring a responsive Kanban board interface, real-time search, voting, and a sleek dark mode UI.

---

## 🚀 Features

* **Kanban Board Workflow:** Organize project ideas across three distinct stages: **Inbox**, **Research**, and **Finalists**.
* **Responsive Mobile Design:** Smooth horizontal scrolling layout tailored for mobile devices to prevent element overlap.
* **Idea Management:** Full CRUD operations to add, edit, and delete project proposals seamlessly.
* **Voting System:** Upvote favorite ideas to prioritize top project choices within the team.
* **Instant Search:** Filter and find project ideas instantly by title using the search bar.
* **Dark Mode UI:** A clean, eye-friendly dark theme built with Tailwind CSS.

## 📦 Getting Started & Installation

Follow these steps to run the project locally on your machine.

### Prerequisites
Make sure you have **Node.js** and **npm** installed.

### 1. Clone the Repository 
```bash
git clone https://github.com/AlaaH0ssam/GP-brainstorming.git
cd GP-brainstorming
Bash
```
### 2. Install Dependencies
```bash
cd client
npm install
```
# Install server dependencies
```bash
cd ../server
npm install
```
### 3. Run the Application
Start the development servers for both the frontend and backend:

```bash 
# Run the client
cd client
npm run dev

# Run the server (in a separate terminal)
cd server
npm run start
```
